# Car_Sales_And_Service_Analysis_Dashboard
To analyze car sales and service data, identify business trends, and provide meaningful insights into vehicle performance

📌 Project Overview

This project focuses on analyzing car sales and service data using SQL Server and Power BI. It combines five different datasets to generate meaningful business insights about vehicle sales, customer ownership, insurance, and service history.

🛠️ Tools & Technologies

- SQL Server (SSMS): Data cleaning, transformation, joins, and analysis.
- Power BI: Interactive dashboards and data visualization.

📂 Datasets

The project uses five datasets:

1. Car Data
2. Sales Data
3. Owners Data
4. Service History
5. Insurance Data

🔍 Project Workflow

1. Data Integration

- Integrated five datasets using SQL JOIN operations.
- Created a consolidated master table.
- Used INNER JOIN and LEFT JOIN.

2. Data Cleaning & Transformation

- Performed data type conversion.
- Handled data inconsistencies.
- Applied aggregate functions.
- Used GROUP BY for summarizing data.

3. Data Analysis

Analyzed:

- Car sales and revenue.
- Car brands and models.
- Fuel types.
- Transmission types.
- Vehicle service costs.
- Yearly sales trends.

4. Power BI Dashboard

Developed an interactive dashboard using:

- KPI Cards
- Bar Charts
- Donut Charts
- Interactive Visualizations

📊 Key Insights

- Analyzed 50K+ car records.
- Identified yearly sales trends.
- Compared vehicle brands and models.
- Analyzed fuel and transmission preferences.
- Evaluated vehicle service performance.

🎯 Project Objectives

- Understand car sales performance.
- Analyze vehicle and service-related data.
- Identify meaningful business trends.
- Support data-driven business decisions.
